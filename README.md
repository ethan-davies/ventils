# Ventils

A Hypixel Skyblock client mod for Minecraft 26.1.2 (Fabric).

## Requirements

- Java **25**
- Minecraft **26.1.2**
- Fabric Loader **0.19.5+**
- Fabric API

## Build

```bash
./gradlew build
```

The installable jar is `build/libs/ventils-1.1.0.jar`.

## Run

```bash
./gradlew runClient
```

In-game, run `/ventils` to open the MoulConfig GUI. The **General > Enabled** toggle is saved to `config/ventils.json`.
